# API de Tarefas Assíncronas com FastAPI e Celery

Projeto desenvolvido para a EBAC que demonstra a execução de tarefas pesadas e assíncronas em segundo plano utilizando FastAPI, Celery e Redis.

## Funcionalidades
- **`/soma`**: Endpoint que simula um cálculo demorado de soma (5 segundos).
- **`/fatorial`**: Endpoint que calcula o fatorial de um número de forma assíncrona.
